# Hoja de vida web

Sitio web responsive para presentar la hoja de vida de Byron Jose Vera Correa.

## Ejecutar

El proyecto no necesita instalación ni dependencias. Puedes abrir `index.html` directamente en el navegador o iniciar un servidor local desde la raíz:

```bash
python3 -m http.server 8000
```

Después visita `http://localhost:8000`.

## Personalizar

- Edita el contenido y los placeholders en `index.html`.
- Cambia colores, tipografías y responsive design en `css/style.css`.
- Ajusta las interacciones en `js/script.js`.
- Sustituye `Habilidad 1` a `Habilidad 4` y actualiza cada atributo `data-level` con un porcentaje entre 0 y 100.
- Coloca la foto como `assets/images/foto-perfil.jpg` y reemplaza el bloque visual de iniciales si deseas mostrarla.
- Añade el archivo `CV-Byron-Jose-Vera-Correa.pdf` en la raíz para activar la descarga del CV.
- Reemplaza los placeholders de experiencia, educación, cursos, certificaciones e idiomas con información real.
